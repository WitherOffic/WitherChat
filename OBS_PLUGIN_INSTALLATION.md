# Установка плагина из WitherChat

В готовом EXE Windows x64: **Настройки → OBS-оверлей → Плагин OBS**.

- Статус: не установлен / установлен / есть обновление.
- OBS обычно находится автоматически, включая Steam. При нескольких установках или переносной версии выберите корневую папку OBS, где находятся папки bin, data и obs-plugins.
- Закройте OBS, нажмите «Установить» или «Обновить». Для защищённой папки Windows может запросить права администратора. Отмена не отмечает плагин установленным.
- Поддерживается проверенная связка OBS 32.2.2 x64 и Qt 6.11.1. Другие версии не устанавливаются вслепую.
- Затем откройте OBS → Сервис → WitherChat. Плагин запускает встроенный EXE, отдельный запуск чата не обязателен.
- Если раньше в плагине вручную выбран другой EXE, выберите установленный data/obs-plugins/witherchat-obs/WitherChat.exe.

Профили, сцены и настройки OBS не изменяются. Предыдущие файлы плагина сохраняются в data/obs-plugins/witherchat-obs-backups. При ошибке записи выполняется откат; при ошибке отката приложение сообщает путь резервной копии.

Плагин и необходимые лицензии включены в EXE. Отдельное скачивание не нужно. Установщик не отключает защиту Windows и не обходит блокировку неподписанных программ.

## Удаление только плагина WitherChat

В том же блоке нажмите «Удалить плагин», затем «Да, удалить». OBS должен быть закрыт. Для защищённой папки Windows может запросить права администратора.

Удаляются только известные файлы WitherChat: DLL, встроенный EXE, комплектуемые лицензии/исходники и такие же файлы в служебных резервных/временных копиях нашего установщика. Неизвестные файлы сохраняются даже внутри папки плагина. Папки удаляются только если пусты; общие каталоги OBS не удаляются. Сам OBS, другие плагины, профили, сцены, настройки OBS и аккаунты чата не затрагиваются.

Если текущий чат запущен из папки плагина, удаление не выполняется: закройте его и запустите отдельный EXE вне папки OBS. Приложение не завершает OBS принудительно и не откладывает удаление до перезагрузки.

Удаление реально и не отменяется кнопкой «Отмена» настроек. Если удаление прервано, часть файлов плагина могла остаться: приложение сообщает, что операция не завершена; безопасно повторите её. Автоматического восстановления удалённых файлов нет. Для повторной установки используйте кнопку «Установить».

Кнопка «?» в блоке плагина открывает отдельное обучение. Общий «Быстрый старт» и обучение настроек также обновлены. В маленьком окне текст прокручивается, кнопки перехода закреплены отдельно. Обучение само ничего не устанавливает и не удаляет. Док OBS — рабочее окно полного чата; оверлей «Браузер» — показ сообщений зрителям.

## Для разработчика

Ресурс Assets/ObsPlugin/windows-x64.zip содержит production-DLL, лицензии и соответствующие исходники GPL-плагина. EXE в ресурс не включается: установщик копирует текущий готовый EXE, избегая рекурсивного встраивания.

При изменении C++-плагина или комплектуемых лицензий обновите ресурс **до** публикации нового EXE:

    pwsh -File build/Prepare-ObsPluginPayload.ps1 -NativeDll <production DLL> -AppPackage <папка готового EXE с лицензиями>

Затем опубликуйте Windows x64 single-file EXE и запустите Package-ObsDock.ps1. Упаковщик проверяет совпадение DLL с встроенным ресурсом. Установка из многокомпонентной Debug-сборки и на других платформах отключена.

Служебные режимы --install-obs-plugin <папка OBS> и --remove-obs-plugin <папка OBS> выполняют только проверку и соответствующую операцию, без запуска интерфейса, входа в аккаунты и чтения профилей чата. Удаление не требует исходной совместимой версии Qt, но проверяет, что цель — локальная папка OBS Windows x64 без junction/symlink-путей.
