# WitherChat

Отдельное окно чата **Twitch и YouTube** для стримеров, модераторов и зрителей.
Помогает следить за сообщениями во время эфира и управлять чатом без лишних вкладок.

## Что умеет

- Показывает сообщения нескольких каналов, значки и эмоции, включая 7TV и BetterTTV.
- Работает в обычном и компактном режиме.
- Даёт поиск, фильтры, закрепление сообщений и локальные логи.
- Позволяет удалять сообщения, выдавать тайм-ауты и баны при наличии прав.
- Поддерживает оверлей OBS и DonationAlerts, светлую и тёмную темы.
