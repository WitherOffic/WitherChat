# WitherChat 0.6

Чат **Twitch и YouTube** для стримеров, модераторов и зрителей.
Работает отдельным окном или полноценной док-панелью внутри OBS.

## Возможности

- Сообщения нескольких каналов, значки и эмоции, включая 7TV и BetterTTV.
- Обычный и компактный режим, светлая и тёмная темы.
- Модерация, история пользователя, поиск, фильтры, локальные логи и сохранённые моменты.
- События стрима, защитные инструменты и DonationAlerts.
- Док OBS с тем же чатом и функциями; в маленькой панели инструменты собраны в меню.
- Установка, обновление и удаление нашего плагина из настроек чата.
- Отдельный оверлей «Браузер» для показа сообщений зрителям и встроенное обучение.

Отправка сообщений и модерация требуют входа в сервис и соответствующих прав.

## Подключить к OBS

В чате: **Настройки → OBS-оверлей → Плагин OBS**.
Закройте OBS, проверьте статус и нажмите «Установить».
При необходимости выберите папку своей установки OBS; Windows может запросить права администратора.
Затем в OBS откройте **Сервис → WitherChat**.

Плагин сам запускает комплектный чат и встраивает его в док: второй EXE запускать не нужно.
Док нужен для управления чатом; оверлей «Браузер» — для вывода сообщений в сцену. Это разные функции.

Проверенная совместимость плагина: **OBS 32.2.2 x64 / Qt 6.11.1**.
Другие версии не устанавливаются без проверки.
Кнопка удаления затрагивает только известные файлы WitherChat, не другие плагины, сцены или профили.
Для удаления OBS должен быть закрыт, а чат запущен отдельным EXE вне папки плагина.

[Подробнее об установке и удалении](OBS_PLUGIN_INSTALLATION.md).

## Подпись и исходники

EXE и DLL **пока не имеют цифровой подписи**; Windows может блокировать запуск.
Не отключайте защиту Windows. Подпись SignPath ещё не подключена.
