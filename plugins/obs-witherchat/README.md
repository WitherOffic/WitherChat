# WitherChat 0.6 — док OBS

Полноценный WitherChat внутри OBS: те же сообщения Twitch/YouTube, аккаунты,
модерация, история, логи, события, моменты, настройки и DonationAlerts.
Это окна приложения, а не веб-копия. В узком доке кнопки собраны в меню.

Плагин сам запускает комплектный EXE в отдельном процессе и встраивает его
в док. Отдельно запускать чат не нужно. Если совместимый чат уже работает,
плагин подключается к нему; настройки и сообщения принадлежат одному экземпляру.

Док служит для работы с чатом. Оверлей «Браузер» предназначен для вывода
сообщений в сцену и не заменяет док.

## Совместимость

Проверены **Windows x64, OBS Studio 32.2.2, Qt 6.11.1.0**.
Другие версии OBS/Qt и ARM64 не считаются совместимыми без отдельной проверки.
EXE и DLL пока без цифровой подписи; защиту Windows не отключайте.

## Установка из чата

1. Скачайте WitherChat 0.6 и закройте OBS.
2. В чате откройте **Настройки → OBS-оверлей → Плагин OBS**.
3. Проверьте найденную папку OBS или выберите корень своей установки.
4. Нажмите «Установить»; защищённая папка может потребовать UAC.
5. Откройте OBS → **Сервис → WitherChat** и разместите док в окне OBS.

Все необходимые файлы уже включены в готовый Windows x64 EXE.
Если ранее вручную выбран другой EXE, укажите комплектный
`data/obs-plugins/witherchat-obs/WitherChat.exe`.

## Ручная установка из ZIP

Закройте OBS и старый WitherChat. Объедините папки `obs-plugins` и `data`
из пакета с такими же папками именно своей установки OBS.

Обычно это `C:\Program Files\obs-studio`.
Для Steam найдите папку через **Управление → Просмотреть локальные файлы**.
Не создавайте вторую папку OBS: плагин должен лежать рядом с установленным OBS.

Заменяйте только `obs-plugins/64bit/witherchat-obs.dll` и комплектные файлы
`data/obs-plugins/witherchat-obs`. Другие плагины, профили и сцены не трогайте.
Обновляйте EXE и DLL из одного пакета.

Дополнительная проверка при установленном PowerShell 7:

    pwsh -File Check-ObsDockCompatibility.ps1 -ObsDirectory "<папка OBS>"

Не меняйте политику безопасности для запуска скрипта.

## Удаление

Закройте OBS и запустите отдельный WitherChat EXE вне его папки.
В настройках нажмите «Удалить плагин», затем подтвердите.
Удаляются только известные файлы нашего плагина и его служебные копии.
Неизвестные файлы, другие плагины, профили, сцены и аккаунты сохраняются.
«Отмена» настроек не восстанавливает удалённый плагин.

Из запущенного комплектного EXE удаление не выполняется — сначала
закройте этот чат и откройте отдельный EXE.

## Работа и ограничения

Вкладка «Чат» содержит основной интерфейс, «Донаты» — окно DonationAlerts.
Размер и положение дока задаёт OBS. При нормальном закрытии OBS чат
возвращается в отдельное окно.

Связь работает через локальный именованный канал текущего пользователя.
Проверяются процесс OBS, родительское окно, сеанс Windows и DPI.
Плагин не запускает трансляцию и не меняет сцены.

Тесты не подтверждают каждый реальный сценарий Twitch/YouTube/DonationAlerts,
все сочетания клавиш OBS или все варианты разных DPI. Авторизация открывается
в браузере, а выбор файлов использует системные диалоги.

## Сборка и лицензии

Нужны MSVC x64, Windows SDK, CMake >= 3.28, исходники OBS 32.2.2 и Qt 6.11.1.

    pwsh -File build/Build-ObsDock.ps1 -QtRoot <qt> -ObsSource <obs-source> -CMakeExe <cmake.exe>

Сборка не устанавливает плагин. Диагностический автозапуск в production-DLL отключён.
Основной EXE: `build/Publish-WitherChat.ps1 -Platform windows -WindowsArchitecture x64 -Version 0.6`.
