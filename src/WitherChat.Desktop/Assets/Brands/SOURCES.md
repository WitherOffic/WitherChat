# Brand asset sources

The application bundles the original or canonical platform marks as local PNG
assets so the Donate page does not depend on network loading.

- Boosty: official Boosty brand kit — https://boosty.to/app/brand
  (`brand_mark_png.zip`, original 655×788 PNG)
- DonationAlerts: UI mark uses vector geometry from the official SVG brand kit —
  https://www.donationalerts.com/brand (`logo-src/svg.zip`, `DA_Alert_Color.svg`).
  The user-supplied transparent 512×512 PNG is retained only as a reference asset.
- Twitch: official Twitch brand assets — https://brand.twitch.com
- YouTube: official Google/YouTube product asset — https://www.youtube.com/howyoutubeworks/resources/brand-resources/
- Steam: canonical Steam mark; brand guidance — https://partner.steamgames.com/doc/marketing/branding
- Telegram: official Telegram press assets — https://telegram.org/press
- TRON: official TRON brand resources — https://tron.network/resources
  (red logomark from the official PNG media kit)
- TON: official TON media assets — https://ton.org/media/
  (circular blue mark from the official `ton_logo.zip`)
- BNB Chain: official brand guidelines — https://www.bnbchain.org/en/brand-guidelines
  (yellow logomark, #F0B90B)
