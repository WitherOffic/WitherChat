# WitherChat 0.5.1A · Windows x64

Отдельное окно чата Twitch и YouTube для стримеров, модераторов и зрителей.

Сообщения нескольких каналов, значки и эмоции, компактный режим, поиск,
локальные логи, модерация, оверлей OBS и DonationAlerts.

## Запуск

Скачайте **WitherChat-0.5.1A-win-x64.exe** и запустите.
Установка и отдельный .NET не нужны. Для отправки сообщений и модерации
войдите в нужный сервис; действия доступны только при наличии прав.

ZIP содержит тот же EXE с лицензиями компонентов. SHA256SUMS.txt позволяет
проверить скачанные файлы.

## Code signing policy

Это экспериментальная **неподписанная** сборка.
Заявка SignPath отправлена и ожидает рассмотрения. Windows Smart App Control
может блокировать запуск; не отключайте защиту Windows ради этой версии.
