# WitherChat 0.6

Чат Twitch и YouTube, который работает отдельным окном или внутри OBS.

## Что нового

- Полноценный док OBS: тот же чат, аккаунты, модерация, история, логи и DonationAlerts.
- Интерфейс дока адаптирован для небольших панелей: короткая строка аккаунта и одно меню инструментов.
- Установка, проверка статуса, обновление и удаление плагина прямо из настроек.
- Удаление требует подтверждения и затрагивает только известные файлы WitherChat; профили, сцены и другие плагины сохраняются.
- Обновлённое обучение: 12 шагов быстрого старта и отдельная подсказка плагина; кнопки перехода доступны в маленьких окнах.
- Исправления компактного режима, модерации, истории, анимаций, фоновых операций и ограничений памяти.

## Скачать и запустить

**WitherChat-0.6-win-x64.exe** — один файл, .NET уже включён.
Portable ZIP содержит этот EXE и лицензии компонентов.
Пакет **WitherChat-0.6-OBS-Dock-win-x64.zip** предназначен для ручной установки плагина; проще установить его из настроек чата.

Плагин проверен с **OBS 32.2.2 x64 / Qt 6.11.1**.
Закройте OBS перед установкой, обновлением или удалением.
Встроенный в плагин EXE не удаляется из самого себя — запустите отдельный EXE вне OBS.

EXE и DLL **не подписаны**. Windows может блокировать запуск; защиту отключать не нужно.
Учётные данные, профили и логи пользователей в релиз не входят.

[Установка плагина](https://github.com/WitherOffic/WitherChat/blob/main/OBS_PLUGIN_INSTALLATION.md)
